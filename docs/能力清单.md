## 二、插件把它们变成了什么

- **开关**：关着时技能可读、动手被拒；打开才建项目/装依赖/渲染。三个入口：面板、工具、一句话。
- **六个工具**：状态、开关、装依赖、查画风、建项目、渲染。
- **一条依赖路径**：Python→venv→playwright→Chromium/Edge→FFmpeg，幂等、带日志、可离线。
- **一个可搬的包**：15.6 MB 便携 zip + 可选离线依赖包。
- **面板**：右下角「动画」，显示开关/依赖/最近成片，4 秒轮询。

## 三、要做出一条片子，还缺什么

插件解决的是「工具链」，不替你决定内容。以下按重要性排：

1. **文案（必须有）**：150–300 字中文，短句、有画面感。`codeanim_new` 只按标点切场景，不会替你写。
2. **画风决策（必须有）**：从 341 条里挑 1 条并**读完原文**（fy 硬规则）；`codeanim_style search/show` 就干这个。
3. **分镜与节奏（必须有）**：`index.html` 里每个场景的视觉动作、字何时落、留白多久。插件给的是可运行骨架，不是成品设计。
4. **字体（建议）**：中文标题建议思源黑体/Noto Sans SC；模板已做字体回退（Source Han Sans → Noto Sans SC → 微软雅黑）。
5. **配音（可选）**：本机有 `dreamina-canvas` CLI（配音/音乐/生图/生视频）与 taptap 的 `text_to_dialogue`；没有音轨也能出片（`--audio` 可选，`apad` 只补静音不循环）。
6. **音乐/音效（可选）**：`text_to_music`、`text_to_sound_effect`、`suno-v6-prompt` 技能可写提示词。
7. **Remotion（不需要）**：fy 支持但本插件 v1 不启用 Node/Remotion 分支，统一走 HTML/Canvas + render_video.py；要 Remotion 时按 fy 的 implementations 自己起 Node 项目。
8. **发布（按需）**：竖屏另给 1080×1920 参数；字幕/封面可用 office 技能出图或文档。

## 四、已知限制（先知道，少踩坑）

- **B6 不在正式库**：它只存在于上游 `示例/` 目录，按 fy 的规则不算第 342 条；本插件没打包示例视频。
- 静帧已全部补齐：`show` 的 `imageExists` 现在恒为 true，可以看图选。
- **Lemo 系列（L）缺依赖文件**：`DEMO.md/paper.js/draw.js/sheet.js/film.js` 上游就没有，`dependency_audit_complete` 恒为 false；当纯文字风格用。
- **X7 二义**：正式库与示例各有一条同名，检索需带 `id` 或 `--kind prompt`；本插件按 catalog 取正式条目。
- **许可**：免费使用与分享，**禁止**包装成付费课程或付费 skill 出售；第三方画风各有许可，见 `style-library/第三方许可/`。
- **渲染速度**：1080p30 约 6–8 秒/秒成片（本机实测 12s 片 ≈73s）；4K 或 60fps 线性变慢。

## 五、建议的第一次出片（约 5 分钟）

```
codeanim_status → codeanim_switch on
codeanim_style search "水墨"        # 或 粒子 / 工程 / 霓虹
codeanim_style show Z1              # 读原文
codeanim_new { name: "第一条", copy: "<150字文案>", style: "Z1", duration: 12 }
# 打开 projects/<项目>/index.html，按 Z1 原文改 3–5 个场景
codeanim_render { project: "<项目>" }
```
