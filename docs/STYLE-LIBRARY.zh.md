# 画风库与预览（341 条）

插件自带一份**唯一**的画风库，运行时位于 `~/.dsh/code-animation/style-library/`（首次 `codeanim_setup` 或打开开关时从插件同步过去）。插件目录内的 `style-library/` 是源副本，不要按相对路径去读它——检索一律走 `codeanim_style`。

## 一、里面有什么

| `风格提示词/` | 341 个 `.md`，每条一个画风的完整提示词正文 |

## 三、三种查法

```
codeanim_style { action: "search", query: "水墨 纸" , limit: 8 }   # 关键词检索，纯 JS
codeanim_style { action: "show",   id: "Z1" }                     # 完整提示词正文 + 有无静帧
codeanim_style { action: "list",   series: "Z" }                  # 按系列列编号
codeanim_style { action: "open_picker" }                          # 离线挑选器绝对路径
```

面板里的「画风库」按钮会把挑选器直接弹在面板内（走 `/code-animation/picker` 路由，静帧通过 `/code-animation/library/...` 前缀读取），不会跳新标签页。

## 四、预览（静帧）到底能帮多少

- **196 / 341 有图**：有图的那条，可以先看效果再决定要不要用它，`show` 返回里 `imageExists: true`。
- **145 / 341 没图**：只有文字描述。这不是缺文件，是上游就没有；这一类当「纯文字风格」用，靠提示词里的配色、字体、镜头语言来判断。
- 静帧是**风格参考**，不是成品画质承诺：同一条提示词在不同模型、不同内容上会走出不同结果。

## 五、硬规矩（来自 fy 方法论）

1. 选画风必须**读完提示词原文**再动手，不许只看标题或缩略图就开写。
2. 一条片子只用一种主画风；要混，先在 `notes.md` 里写清「哪一段用哪条、怎么接」。
3. 提示词里带 `{{ }}` 的是**要你填**的位置（颜色、时间、镜头），不是装饰。
4. 提示词写得越死（颜色、时长、镜头都写清），不同模型出来的结果越接近；只给一句话也能做，但每次都不一样。
