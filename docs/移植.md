# 移植到别的电脑

[English](./PORTING.en.md)

## 一、便携包（推荐）

```
node scripts/pack.mjs --out N:\DSHreb\deliver
# → dsh-fy-code-animation-1.0.0-portable.zip  ≈15.6 MB
```

zip 里是「插件目录 + 安装.cmd + 使用说明.txt」。目标电脑：

1. 解压到任意位置（路径别带 `&`、`%`）；
2. 双击 `安装.cmd`（内部调用 `dsh plugin add <解压后的 dsh-fy-code-animation 文件夹>`）；
3. 重启 DeepSeek Harness；
4. 说「开启动画模式」，或点右下角面板开关；
5. 首次出片前让助手跑 `codeanim_setup`（依赖是按机器装的，不随包走）。

## 二、拷整个插件目录（不打包也行）

把 `dsh-fy-code-animation` 文件夹整体拷过去，然后在 DSH 里让助手：

```
plugin_manager install_bundle target="<本机绝对路径>"
plugin_manager set_plugin target="include:code-animation" enabled=true
```

或用 CLI：`dsh plugin add "<路径>"`。
本机开发态用的是 `link:/path/to/dsh-fy-code-animation`，改代码后重新 `set_plugin` 一次即可热更新。

## 三、依赖要不要跟着走

| 方案 | 体积 | 适用 |
| --- | --- | --- |
| 不打包依赖 | 0 | 目标机能联网（默认） |
| 离线依赖包 | ≈330–500 MB | 目标机断网/内网 |

```
node scripts/build-offline-pack.mjs --zip
# → dsh-fy-code-animation-offline-deps.zip（wheels + chromium + ffmpeg）
```

目标机解压到 `~/.dsh/code-animation/offline/`（得到 `offline/wheels`、`offline/browsers`），再跑 `codeanim_setup`：pip 走本地 wheel，Chromium 从 `offline/browsers` 找。

## 四、运行时数据在哪

`~/.dsh/code-animation/`：

```
env/            独立 venv（可删，重装）
tools/ffmpeg/   自带 ffmpeg
skills/         技能同步副本（供 fy 写 style-index）
style-library/  341 画风（插件内唯一副本的镜像）
projects/       项目
output/         成片
logs/           setup.log / render.log
state.json      开关与最近记录
deps.json       依赖快照
```

删掉整个目录 = 回到「刚装好、未配置」；插件本体与技能不受影响。

## 五、换机检查表

- [ ] 目标机有 DeepSeek Harness（Windows）
- [ ] `安装.cmd` 找到 `dsh.cmd`（找不到就手动 `dsh plugin add`）
- [ ] 重启后技能目录出现 `code-animation-prompts`、`fy-code-animation`
- [ ] 工具表出现 `codeanim_*` 六个工具
- [ ] `codeanim_status` 五步全绿、画风库 341 条
- [ ] 渲一条 3 秒测试片确认编码正常
