## 结论

| 用途 | 需要 | 大小 | 获取方式 |
| --- | --- | --- | --- |
| 检索画风 / 建项目 / 校验任务卡 | Python 3.10+ | 已有 | 系统里任意 3.10+；没有就装一个 |
| 渲染（截图） | Playwright + Chromium | ≈40 MB + 436 MB | `codeanim_setup` 自动装；下载不动自动降级本机 Edge |
| 编码 | FFmpeg | ≈80 MB | 从 `imageio-ffmpeg` 里取一份放到 `tools/ffmpeg/bin` |

插件本体 15.6 MB（341 画风 + 196 静帧 + 两套技能），**不含** Python 与浏览器。

## 自动装配做了什么

`codeanim_setup`（或装机时的 `postinstall` 后台任务）按顺序执行，全部幂等：

1. **python** —— 依次尝试 `CODEANIM_PYTHON` → 插件离线工具 → `py -3.12/3.11/3.10` → `python3` → `python` → Anaconda；只接受 ≥3.10
2. **venv** —— 在 `~/.dsh/code-animation/env` 建独立虚拟环境，不污染系统 Python
3. **pip** —— 装 `playwright` + `imageio-ffmpeg`；默认 PyPI，失败自动切清华镜像；有 `offline/wheels` 时优先离线装
4. **chromium** —— `python -m playwright install chromium`；失败自动切 `cdn.npmmirror.com` 镜像；仍失败则**降级用本机 Edge**（`channel: "msedge"`，不下载浏览器）
5. **ffmpeg** —— 先看系统 PATH，再从 `imageio_ffmpeg` 取可执行文件复制到 `tools/ffmpeg/bin/ffmpeg.exe`；渲染时只把该目录前置到 PATH，**不改系统 PATH**
6. **verify** —— 重新体检五步并写 `deps.json`

## 卡住怎么办

- **Chromium 下载慢/失败**：不用管，插件会自动用本机 Edge（Windows 10/11 自带）。`deps.json` 里会看到 `chromium: { channel: "msedge" }`。
- **playwright install 超时**：`codeanim_setup({ steps: ["chromium"] })` 重跑；或手动设 `PLAYWRIGHT_DOWNLOAD_HOST=https://cdn.npmmirror.com/binaries/playwright`。
- **pip 装不上**：`codeanim_setup({ steps: ["pip"] })`；镜像在 `lib/deps.js` 的 `PYPI_MIRROR`。
- **完全断网**：先在能联网的机器上跑 `node scripts/build-offline-pack.mjs --zip`，把 zip 解压到目标机 `~/.dsh/code-animation/offline/`，再 `codeanim_setup`。
- **想看细节**：`~/.dsh/code-animation/logs/setup.log`（UTF-8，PowerShell 读时加 `-Encoding UTF8`）、`render.log`。

## 为什么不改系统环境

- 不写系统 PATH、不装全局包、不动注册表；
- 播放器兼容性靠 `libx264 + yuv420p + crf18 + faststart` 固定；
- 换电脑=拷插件 + 跑一次 setup，行为一致。
