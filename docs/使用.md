# 使用

[English](./USAGE.en.md)

## 右下角面板

页面右下角默认只有一个 **46px 圆点**（不挡内容），点一下才展开完整面板：

- **收起态**：圆点绿=动画模式开、灰=关，鼠标悬停可看状态提示，占位仅 46×46
- **开关**（标题或开关本体）：开/关动画模式，操作后给回执（如「已开启 19:41:32」）
- **画风库**：在面板内弹出 341 条风格挑选器，带缩略图，可搜索、按系列筛、勾选后复制清单；Esc 或「关闭」退出，页面不会跳到新标签
- **刷新**：重新读取状态，显示「已刷新 HH:MM:SS」
- **状态行**：动画模式 / 依赖就绪 / 画风库条数 / 最近成片
- **收起**：标题栏「–」把面板收回圆点；展开/收起状态会被记住；展开后 12 秒没动静自动收起（弹层打开时不收）

面板每 4 秒自动轮询一次；插件升级或改了 `client.js` 之后，要按一次 **Ctrl+R** 重新加载页面才会用上新版面板。

## 工具一览

### codeanim_status

无参数。返回开关状态、五步依赖、画风库条数、最近项目/成片、默认规格。**动手前先看它**。

### codeanim_switch

`{ action: "on" | "off" | "toggle" }`。关闭时技能仍可读，但建项目/装依赖/渲染会被拒绝并提示怎么开。
三个入口等价：面板开关、这个工具、直接说「开启动画模式」。

### codeanim_setup

`{ steps?: ["python","venv","pip","chromium","ffmpeg","verify"], offline_pack?: true }`。
幂等；已完成的步骤会秒过。`setup.log` 记录每步耗时与失败原因。

### codeanim_style

- `{ action: "search", query: "水墨", limit: 8 }` —— 纯 JS 检索，不依赖 Python
- `{ action: "show", id: "B3" }` —— 返回该画风 Markdown 全文 + 是否有参考静帧
- `{ action: "list", series: "Z" }` —— 按系列列编号
- `{ action: "open_picker" }` —— 离线挑选器绝对路径（浏览器直接打开 `风格挑选.html`）

系列：AG 代码样片 26、M 动态 40、K 卡通 38、Z 中国风 15、H 版式 12、L Lemo 59、V mg-styles 15、X code-video 31、R 参照 7、O 奥斯卡 98。

### codeanim_new

`{ name, copy, style?, duration?, width?, height?, fps? }`

- 按句号/问号/感叹号/分号/换行切句，再按 34 字上下合并成场景（最多 2 句一场）
- 按字数分配时长，单场不短于 2.2s，最后一场吃掉剩余时长
- 写 `task.json`（fy 契约）并**当场跑 fy 的 `validate_task.py`**，不通过就报错不建项目
- 同时生成可渲染的 `index.html` 占位分镜（逐字显现、纯函数 `renderAt(t)`）

### codeanim_render

`{ project?, output?, name?, duration?, fps?, width?, height?, audio? }`

- `project` 可以是项目目录或 HTML 文件；不填用最近项目
- 宽/高必须是正偶数，fps 1–120，时长 0–300s
- 渲染后回读 ffmpeg 元数据（分辨率/时长/帧率/体积），不靠「进程退出 0」判断成功
- Chromium 起不来会自动用本机 Edge 重试一次
- 输出重名自动加 `-YYYYMMDD-HHmmss`

## 一条完整路径（约 3 分钟）

```
codeanim_status                          # 依赖 OK、开关 OFF
codeanim_switch { action: "on" }
codeanim_style  { action: "search", query: "粒子" }
codeanim_style  { action: "show", id: "B3" }        # 读完再动手（fy 的硬规则）
codeanim_new    { name: "开场", copy: "文案……", style: "B3", duration: 12 }
# 打开 projects/<项目>/index.html，按 B3 的原文改分镜
codeanim_render { project: "projects/<项目>", duration: 12 }
```

## 项目结构

```
projects/<name>-<时间戳>/
  index.html      可渲染的分镜（必须暴露 window.renderAt(t)，?export=1 时纯函数）
  input/copy.txt  文案
  task.json       任务卡（phase/scenes/events/music/evidence）
  notes.md        10 步顺序 + 画风原文节选 + 待办
```

想手工接管：改 `index.html` 的文案与时间轴，`task.json` 里补 `scenes/events`，再 `codeanim_render`。
`codeanim_new` 只做 `phase: "card"`；要交付 `still/audition/final` 时按 fy 的 `templates/task.json` 改 phase 与 actions 白名单。

## 出问题怎么办

1. 面板没出现：按一次 **Ctrl+R** 刷新界面（改过 `lib/client.js` 后必须刷新）。
2. 面板里的「刷新」只读状态；要改开关请点右上角的开关本体。
3. **启用插件后 DSH 打不开**（1.0.1 的 bug，1.0.2 已修）：
   - 先记住这次的教训：客户端 bundle 必须导出 `apply`，否则 boot 阶段会抛
     `invalid plugin, expect function or object with an "apply" method`。
   - 紧急回滚不用开 GUI：双击插件包附带的 `停用本插件.cmd`
     （或手跑 `node scripts/toggle-profile.mjs --profile desktop --off`），然后重启 DSH。
   - 想再打开：`--on`，或双击 `启用本插件.cmd`。
4. 依赖没装好：跑 `codeanim_setup`；失败原因写在 `%USERPROFILE%\.dsh\code-animation\logs\setup.log`。
5. 想彻底静音：在 `%USERPROFILE%\.dsh\code-animation\` 下建一个名为 `DISABLE` 的空文件，
   下次启动插件只加载外壳、不注册工具/技能/路由（删掉文件即恢复）。
